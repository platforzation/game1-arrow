# 一箭又一箭（Arrow Click）

> 软件工程个人作业：使用 Python + Pygame 与 AIGC 辅助开发的点击式箭头解谜小游戏。

## 项目简介

“一箭又一箭”是一款点击式箭头解谜游戏（玩法参考“羊了个羊”同类的休闲小游戏，仅参考核心玩法，未使用原游戏任何素材、代码或关卡）。

棋盘上分布着朝上、下、左、右四个方向的箭头。玩家点击箭头后：

- 若箭头前进方向直到棋盘边界之间**没有其他箭头**，箭头飞出棋盘并被消除；
- 若路径上**存在其他箭头**，箭头保留，并以晃动、变色和提示文字给出碰撞反馈，同时**消耗 1 次失误机会**；
- 每关有 3 次失误机会，**清空本关全部箭头即通关**，失误次数耗尽则本关失败。

## 开发环境

| 项目 | 说明 |
| --- | --- |
| 操作系统 | Windows 10/11 |
| 语言 | Python 3.14（3.10+ 均可运行） |
| 图形库 | pygame-ce 2.5.8（`import pygame` 使用，兼容官方 pygame） |

> 说明：Python 3.14 尚无官方 pygame 的预编译包，本项目使用社区维护的 `pygame-ce`，导入方式与官方 pygame 完全一致；若使用 Python 3.12 及以下，安装官方 `pygame` 亦可运行。

## 安装和运行方法

```bash
# 1. 安装依赖（推荐使用虚拟环境）
pip install -r requirements.txt

# 2. 运行游戏
python main.py
```

运行自动化测试：

```bash
python -m unittest discover -s tests -v
```

## 游戏操作说明

| 操作 | 说明 |
| --- | --- |
| 鼠标左键点击箭头 | 尝试让箭头飞出棋盘；被阻挡则产生碰撞反馈并扣除失误次数 |
| 点击“提示”按钮（或按 `H`） | 高亮一个当前可以飞出的箭头 |
| 点击“撤销”按钮（或按 `Z`） | 撤销上一次成功的飞出 |
| 点击“重新开始”按钮（或按 `R`） | 当前关卡恢复初始状态 |
| 按 `Esc` | 返回主菜单 |

界面包含：

- **开始界面**：游戏标题、规则说明、开始游戏 / 选择关卡 / 退出；
- **游戏界面**：顶部信息栏（当前关卡、剩余箭头数量、剩余失误次数）与菜单/重新开始/提示/撤销按钮，中央棋盘；
- **通关 / 失败 / 全部通关界面**：结算弹窗与后续操作按钮。

## 关卡设计

共 6 关（4×4 ~ 7×7），每一关都通过内置求解器验证存在通关顺序：

| 关卡 | 名称 | 棋盘大小 |
| --- | --- | --- |
| 1 | 入门 | 4×4 |
| 2 | 基础 | 5×5 |
| 3 | 进阶 | 5×5 |
| 4 | 挑战 | 6×6 |
| 5 | 高手 | 6×6 |
| 6 | 大师 | 7×7 |

设计要点：同一行不能出现“`>` 在 `<` 左侧且无其他可移除障碍”、同一列不能出现“`v` 在 `^` 上方”等**互堵死锁**结构；初版关卡曾出现两处死锁，被求解器测试发现后已人工调整。

## 测试

运行 `python -m unittest discover -s tests -v`，共 **19 项测试**全部通过，覆盖：

- T01 点击前方无阻挡的箭头 → 飞出并消失；
- T02 点击前方有阻挡的箭头 → 不消失、失误次数减 1；
- T03 边缘朝外的箭头 → 正常消失、不越界；
- T04 清空全部箭头 → 通关并可进入下一关；
- T05 失误耗尽 → 失败并允许重新开始；
- T06 进行中重新开始 → 布局与失误次数恢复；
- 全部关卡合法且可解、互堵关卡能被判定为不可解；
- UI 冒烟测试（各界面可绘制、点击流程正常）。

## AIGC 使用说明

本项目使用 **豆包（Doubao）AI 编程助手** 辅助开发，包括：环境与依赖选择、四方向路径检测、关卡数据设计、碰撞/飞出动画、自动化测试编写等。AI 生成代码中发现的典型问题（方向向量写错、关卡互堵死锁、动画参数类型错误）均经测试或人工审查后修正。详细协作记录见《博客文档》。
