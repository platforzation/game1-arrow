# 一箭又一箭（Arrow Click）

> 软件工程个人作业：使用 Python + Pygame 与 AIGC 辅助开发的点击式箭头解谜小游戏。

## 项目简介

“一箭又一箭”是一款点击式箭头解谜游戏（玩法参考“羊了个羊”同类的休闲小游戏，仅参考核心玩法，未使用原游戏任何素材、代码或关卡）。

棋盘上分布着朝上、下、左、右四个方向的箭头。玩家点击箭头后：

- 若箭头前进方向直到棋盘边界之间**没有其他箭头**，箭头飞出棋盘并被消除；
- 若路径上**存在其他箭头**，箭头保留，并以晃动、变色和提示文字给出碰撞反馈，同时**消耗 1 次失误机会**；
- 每关有 2~3 次失误机会（前 6 关 3 次，后 4 关 2 次），**每关限时**（60~160 秒），**清空本关全部箭头即通关**；失误次数耗尽或超时则本关失败。

| 项目 | 说明 |

## 安装和运行方法

```bash
# 1. 安装依赖（推荐使用虚拟环境）
pip install -r requirements.txt

# 2. 运行游戏
python main.py
```

运行自动化测试：

```bash
python -m unittest discover -s tests -v
```

## 游戏操作说明

| 操作 | 说明 |
| --- | --- |
| 鼠标左键点击箭头 | 尝试让箭头飞出棋盘；被阻挡则产生碰撞反馈并扣除失误次数 |
| 点击“提示”按钮（或按 `H`） | 高亮一个当前可以飞出的箭头 |
| 点击“撤销”按钮（或按 `Z`） | 撤销上一次成功的飞出 |
| 点击“重新开始”按钮（或按 `R`） | 当前关卡恢复初始状态（失误次数、剩余时间一并恢复） |
| 按 `Esc` | 返回主菜单 |

每关都有**倒计时**：时间显示在界面右上角，最后 30 秒变红提醒；倒计时归零本关直接失败。

界面包含：

- **开始界面**：游戏标题、规则说明、开始游戏 / 选择关卡 / 退出；
- **游戏界面**：顶部信息栏（当前关卡、剩余箭头数量、剩余失误次数、剩余时间）与菜单/重新开始/提示/撤销按钮，中央棋盘（大关卡自动缩小格子以完整显示）；
- **通关 / 失败 / 全部通关界面**：结算弹窗与后续操作按钮（失败界面会区分“失误耗尽”与“时间耗尽”）。

## 项目结构


## 关卡设计

共 10 关（4×4 ~ 9×9），难度逐步提升：棋盘更大、箭头更多更纠缠、失误次数更少（后 4 关 2 次）、限时更短。每一关都通过内置求解器验证存在通关顺序：

| 关卡 | 名称 | 棋盘大小 | 箭头数 | 失误上限 | 限时 |
| --- | --- | --- | --- | --- | --- |
| 1 | 入门 | 4×4 | 5 | 3 | 60s |
| 2 | 基础 | 5×5 | 7 | 3 | 75s |
| 3 | 进阶 | 5×5 | 9 | 3 | 75s |
| 4 | 挑战 | 6×6 | 9 | 3 | 90s |
| 5 | 高手 | 6×6 | 10 | 3 | 100s |
| 6 | 大师 | 7×7 | 12 | 3 | 110s |
| 7 | 宗师 | 7×7 | 14 | 2 | 120s |
| 8 | 传说 | 8×8 | 16 | 2 | 140s |
| 9 | 王者 | 9×9 | 18 | 2 | 160s |
| 10 | 终极 | 9×9 | 20 | 2 | 160s |

设计要点：同一行不能出现“`>` 在 `<` 左侧且无其他可移除障碍”、同一列不能出现“`v` 在 `^` 上方”等**互堵死锁**结构；初版关卡曾出现多处死锁，被求解器测试发现后已人工调整。第 7~10 关使用 `tools/gen_level.py` 逆向生成（每放置一个箭头都用求解器验证仍可解），再经过“方向翻转优化”把初始可直接飞出的箭头压到 2~4 支，保证关卡有一定解谜深度。

## 测试

运行 `python -m unittest discover -s tests -v`，共 **28 项测试**全部通过，覆盖：

- T01 点击前方无阻挡的箭头 → 飞出并消失；
- T02 点击前方有阻挡的箭头 → 不消失、失误次数减 1；
- T03 边缘朝外的箭头 → 正常消失、不越界；
- T04 清空全部箭头 → 通关并可进入下一关；
- T05 失误耗尽 → 失败并允许重新开始；
- T06 进行中重新开始 → 布局与失误次数恢复；
- T07 时间限制 → 倒计时递减、超时判负（lose_reason='time'）、重开恢复时间、通关后停止计时；
- 全部关卡合法且可解（`tools/validate_levels.py` 可复核）、互堵关卡能被判定为不可解；
- UI 冒烟测试（各界面可绘制、点击流程正常、超时进入失败界面、HUD 显示倒计时）。

## AIGC 使用说明

本项目使用 **豆包（Doubao）AI 编程助手** 辅助开发，包括：环境与依赖选择、四方向路径检测、关卡数据设计、碰撞/飞出动画、自动化测试编写、可解关卡生成算法等。AI 生成代码中发现的典型问题（方向向量写错、关卡互堵死锁、动画参数类型错误、`get_font` 参数不匹配）均经测试或人工审查后修正。详细协作记录见《博客文档》。

## 扩展功能（附加分）

- 关卡选择界面（10 关自由选择）；
- 提示功能（高亮可飞出箭头）；
- 撤销上一步（撤销成功的飞出）；

- 飞出淡出动画、碰撞晃动与变色反馈、提示光圈动画、按钮悬停效果；
- 快捷键（R / H / Z / Esc）。
